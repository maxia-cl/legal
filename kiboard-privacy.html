Política de privacidad de KiBoard

Vigente desde: 15 de septiembre de 2026

KiBoard, publicada por Ricardo Méndez (MendeX), convierte un teléfono o tablet Android en una superficie de control para un PC Windows en la misma red local. KiBoard no muestra publicidad, no crea cuentas y no vende datos. El host de Windows utiliza Aptabase para analítica anónima de uso.

Datos que maneja la aplicación

  • Conexión de red local: la app descubre y se conecta al host KiBoard de Windows. El token de emparejamiento, la dirección del host y su certificado se guardan localmente en Android para permitir la reconexión.
  • Micrófono: KiBoard accede al micrófono únicamente cuando el usuario inicia el dictado. El servicio de reconocimiento configurado en Android realiza la transcripción. KiBoard envía el texto resultante al PC emparejado por la red local y no envía audio a servidores operados por KiBoard.
  • Interacciones: las pulsaciones y movimientos del trackpad se envían al PC emparejado para ejecutar la acción solicitada. El host genera eventos de analítica con el tipo de interacción y contexto funcional general. El texto ingresado o dictado y el contenido de las acciones no se incluyen en esos eventos.

Analítica anónima

Los eventos se envían desde el host Windows a la región de Estados Unidos de Aptabase. Incluyen la versión, idioma, sistema operativo, tipo de interacción y un identificador aleatorio limitado a la ejecución actual del host. No incluyen nombres de aplicaciones, ventanas, dispositivos, tableros o perfiles; etiquetas o acciones personalizadas; texto escrito o dictado; audio; direcciones locales; códigos o tokens de emparejamiento ni certificados.

Aptabase indica que genera un identificador diario en el servidor a partir de la dirección IP, el agente de usuario y una sal rotativa, y que conserva eventos hasta por cinco años. Consulta su política de privacidad. La analítica se puede desactivar desde la configuración del host Windows.

Terceros

Las excepciones al procesamiento local son Aptabase, para la analítica descrita arriba, y el proveedor de reconocimiento de voz configurado en Android cuando el usuario usa el dictado.

Conservación y eliminación

La información de emparejamiento permanece en Android hasta que el usuario se desconecta, borra los datos de la app o desinstala KiBoard. La configuración del host permanece en el PC hasta que el usuario la elimina. Los eventos de Aptabase no contienen una cuenta ni un identificador permanente que permita asociarlos a una persona para eliminarlos selectivamente.

Seguridad

KiBoard empareja cada dispositivo con un token propio, usa conexiones WebSocket cifradas y fija el certificado del host emparejado. Se recomienda emparejar sólo con un PC controlado por el usuario y usar una red local confiable.

Menores

KiBoard es una herramienta general de productividad y no está dirigida a menores.
